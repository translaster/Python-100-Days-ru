## Расширенное использование функций

Мы продолжаем изучать то, что знаем об определении и использовании функций. Как мы узнали из предыдущего раздела, функции имеют независимые переменные (параметры) и зависимые переменные (возвращаемые значения), и что независимые переменные могут быть любого типа данных, но и зависимые переменные также могут быть любого типа, поэтому здесь возникает небольшой вопрос: можем ли мы использовать функцию в качестве параметра функции и в качестве возвращаемого значения? Начнем с вывода: **функция Python - это "функция первого класса"**, что означает, что функция может быть присвоена переменной, функция может быть использована в качестве параметра функции, функция также может быть использована в качестве возвращаемого значения функции. Использование функции в качестве аргумента или возвращаемого значения другой функции часто называют "функцией высшего порядка".

### Функции высшего порядка

Давайте вернемся к примеру, о котором мы говорили ранее, и разработаем функцию, передающую любое количество параметров и реализующую операцию суммирования по элементам типа `int` или `float`. Мы немного изменим предыдущий код, чтобы сделать его более компактным, как показано ниже.

```python
def calc(*args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = 0
    for item in items:
        if type(item) in (int, float):
            result += item
    return result
```

Что, если мы хотим, чтобы функция `calc`, описанная выше, могла не просто суммировать несколько аргументов, но и реализовывать дополнительные или даже пользовательские бинарные операции? Приведенный выше код может суммировать только потому, что в функции используется оператор `+=`, который связывает функцию с операцией сложения, и если его можно отвязать, функция станет более универсальной и гибкой. Способ отвязки заключается в том, что оператор `+=` вставляется в вызов функции, и будет оформлен как параметр функции, код показан ниже.

```python
def calc(init_value, op_func, *args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = init_value
    for item in items:
        if type(item) in (int, float):
            result = op_func(result, item)
    return result
```

Обратите внимание, что приведенная выше функция добавляет два параметра, где `init_value` представляет начальное значение операции, а `op_func` - функцию бинарной операции. Чтобы вызвать модифицированную функцию, мы сначала определяем функцию, которая выполняет операции сложения и умножения, код показан ниже.

```python
def add(x, y):
    return x + y


def mul(x, y):
    return x * y
```

Чтобы выполнить операцию суммирования, мы можем вызвать функцию `calc` следующим образом.

```python
print(calc(0, add, 1, 2, 3, 4, 5))  # 15
```

Чтобы выполнить операцию над произведением, мы можем вызвать функцию `calc` следующим образом.

```python
print(calc(1, mul, 1, 2, 3, 4, 5))  # 120 
```

Приведенная выше функция `calc` объединяется с операцией сложения путем превращения оператора в параметр функции, что является очень умным и практичным приемом программирования, но для начинающих может показаться сложным для понимания, поэтому рекомендуется его изучить (осмыслить). Обратите внимание, что в приведенном выше коде, функция в качестве параметра для других функций и прямой вызов функции имеют существенную разницу, **вызов функции должен сопровождаться круглыми скобками в имени функции, в то время как функция в качестве параметра используется только по имени**.

Если у вас нет заранее определенных функций `add` и `mul`, то можете использовать функции `add` и `mul`, предоставляемые модулем `operator` стандартной библиотеки Python, которые представляют бинарные операции сложения и умножения, соответственно, и которые мы можем взять и использовать напрямую, как показано в следующем коде.

```python
import operator

print(calc(0, operator.add, 1, 2, 3, 4, 5))  # 15
print(calc(1, operator.mul, 1, 2, 3, 4, 5))  # 120
```

Встроенные функции Python включают в себя ряд функций высшего порядка, в том числе функции `filter` и `map`, о которых мы упоминали ранее. Например, если мы хотим удалить нечетные числа из списка целых чисел и возвести в квадрат все четные числа, чтобы получить новый список, вы можете использовать эти две функции для этого. Функции для этого используются следующим образом.

```python
def is_even(num):
    """Является ли num четным числом"""
    return num % 2 == 0


def square(num):
    """Возведение в квадрат"""
    return num ** 2


old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(square, filter(is_even, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

Конечно, для реализации функциональности приведенного выше кода можно также использовать генератор списков, что гораздо проще и элегантнее.

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = [num ** 2 for num in old_nums if num % 2 == 0]
print(new_nums)  # [144, 64, 3600, 2704]
```

Давайте обсудим встроенную функцию `sorted`, которая сортирует элементы контейнерного типа данных (например, списка, словаря и т.д.). Мы уже говорили о методе `sort` типа `list`, который сортирует элементы списка. Функция `sorted` функционально неотличима от метода списка `sort`, за исключением того, что она возвращает объект отсортированного списка, а не изменяет исходный список напрямую, что называется **function side-effect-free design**, то есть вызов функции не оказывает никакого влияния на состояние программы или внешней среды, кроме как получения возвращаемого значения. При сортировке с помощью функции `sorted` вы можете настраивать правила сортировки в виде функций более высокого порядка, как показано в следующем примере.

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings)
print(new_strings)  # ['apple', 'in', 'pear', waxberry', 'zoo']
```

В приведенном выше коде нет ничего нового, но если вы хотите сортировать элементы списка на основе длины строки, а не в алфавитном порядке, то можете передать параметр с именем `key` функции `sorted` и присвоить параметру `key` функцию `len`, которая получает длину строки (мы рассматривали в предыдущем уроке с кодом).

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings, key=len)
print(new_strings)  # ['in', 'zoo', 'pear', 'apple', 'waxberry']
```

> **Примечание**: Метод `sort` типа list имеет тот же параметр `key`, так что заинтересованный читатель может опробовать его самостоятельно.

### Лямбда-функции

При использовании функций более высокого порядка, если сама функция в качестве параметра или возвращаемого значения очень проста и может быть завершена в одной строке кода, и вам не нужно рассматривать повторное использование функции, то вы можете использовать лямбда-функцию. Лямбда-функции в Python - это неименованные функции, поэтому многие люди также называют их **анонимными функциями**. Лямбда-функции может содержать только одну строку кода, а результат выражения в коде - это возвращаемое значение анонимной функции. В предыдущем коде мы написали функции `is_even` и `square`, состоящие только из одной строки кода, мы можем заменить их на лямбда-функции, как показано в следующем коде.

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

Как видно из приведенного выше кода, ключевым словом для определения лямбда-функции является `lambda`, за которым следуют параметры функции, если параметров несколько, разделенные запятыми; часть после двоеточия - это исполняемая функция, которая обычно является выражением, а результат выражения - это возвращаемое значение лямбда-функции, поэтому ключевое слово `return` писать не нужно.

Как мы уже говорили, функции в Python - это «функции первого класса», которые можно напрямую присваивать переменным. После изучения лямбда-функций некоторые функции, о которых мы писали ранее, могут быть реализованы в одной строке кода. Вы можете проверить, сможете ли вы понять следующие функции для вычисления факториала и определения простых чисел.

```python
import functools
import operator

# Реализация функции, вычисляющей факториалы, в одной строке кода
fac = lambda n: functools.reduce(operator.mul, range(2, n + 1), 1)

# Функция для определения простых чисел в одной строке кода
is_prime = lambda x: all(map(lambda f: x % f, range(2, int(x ** 0.5) + 1)))

# Вызов лямбда-функций
print(fac(6))        # 720
print(is_prime(37))  # True
```

> ** Подсказка 1**: Функция `reduce`, использованная выше, - это функция из модуля `functools` стандартной библиотеки Python, выполняющая редуктивную операцию над набором данных, подобно функции `calc`, которую мы определили ранее. Первый аргумент - это функция, представляющая операцию, второй - данные для операции, а третий - начальное значение операции. Очевидно, что функция `reduce` также является функцией высшего порядка, и вместе с функциями `filter` и `map` она представляет собой три очень важных действия при обработке данных: **фильтрация**, **сопоставление** и **редукция**.
>
> **Примечание 2**: приведенная выше лямбда-функция для определения простых чисел строит диапазон от 2 до $\small{\sqrt{x}}$ с помощью функции `range`, которая проверяет, что диапазон не имеет множителей для `x`. Функция `all` также является встроенной функцией Python; если все булевы значения в переданной последовательности равны `True`, то функция `all` возвращает `True`, в противном случае - `False`.

### Частичные функции

Частичная функция - это функция, которая изменяет некоторые аргументы функции для создания новой функции, чтобы не передавать одни и те же аргументы при каждом вызове функции. В Python для создания частичных функций можно использовать функцию `partial` из модуля `functools`. Например, функция `int` по умолчанию преобразует строки в десятичные целые числа; если мы изменим ее параметр `base`, то сможем определить три новые функции, которые преобразуют двоичные, восьмеричные и шестнадцатеричные строки в целые числа, как показано в следующем коде.

```python
import functools

int2 = functools.partial(int, base=2)
int8 = functools.partial(int, base=8)
int16 = functools.partial(int, base=16)

print(int('1001'))    # 1001

print(int2('1001'))   # 9
print(int8('1001'))   # 513
print(int16('1001'))  # 4097
```

Не знаю, заметили ли вы, но первый параметр и возвращаемое значение функции `partial` - обе функции, и они обрабатывают входящую функцию, чтобы вернуть новую. Построив частичную функцию, мы можем превратить исходную функцию в новую, которую удобнее использовать в реальном сценарии, не знаю, найдете ли вы эту операцию интересной.

### Резюме

Функции в Python - это функции первого класса, которые можно присваивать переменным или использовать в качестве аргументов и возвращаемых значений для функций, это означает, что в Python можно использовать функции высшего порядка. Концепция функций высшего порядка не очень удобна для новичков, но она обеспечивает гибкость при проектировании функций. Если мы определяем очень простую функцию, состоящую всего из одной строки кода, и нам не нужно имя функции для ее повторного использования, то мы можем использовать лямбда-функцию.
